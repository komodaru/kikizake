# ntstr clauses (spec/README.md): <id> <status> | <source> | <what it says>
# ntdll's integer <-> string conversions. Found clean-room (re/README.md) where Learn is silent:
# assumed until the golden ntstr answers settle them.
NT.A2I.SYNTAX doc | RtlCharToInteger | RtlCharToInteger reads "[whitespace] [{+ | -}] [0 [{x | o | b}]] [digits]" from a NUL-terminated string and returns STATUS_SUCCESS (the prefixes lowercase only; a 0 followed by anything else is a digit 0)
NT.A2I.BASE doc | RtlCharToInteger | "Only base 2, 8, 10, and 16 are supported." (0: by the prefix, else 10); any other base returns STATUS_INVALID_PARAMETER (0xc000000d) and leaves the value as it was
NT.A2I.BLANK assumed | RtlCharToInteger (the clean-room notes) | white space is every byte that is 0x20 or less as a signed char (0x00 .. 0x20 and 0x80 .. 0xff); a blank byte is passed only while the byte after it is not NUL
NT.U2I.EMPTY doc | RtlUnicodeStringToInteger | "If the string is empty, the routine fails and returns STATUS_INVALID_PARAMETER." So does an odd Length (bytes) and a base other than 0, 2, 8, 10, 16; in all three the value is set to 0
NT.U2I.PREFIX doc | RtlUnicodeStringToInteger | base 0: "If the prefix is "0x", RtlUnicodeStringToInteger interprets the number in the string as a hexadecimal integer." ("0o" octal, "0b" binary, lowercase only; otherwise base 10); with a base given no prefix is read
NT.U2I.BLANK assumed | RtlUnicodeStringToInteger (the clean-room notes) | only Length / 2 units are read; white space is every unit 0x20 or less; a 0 unit ends the number
NT.SIGN doc | RtlUnicodeStringToInteger, RtlCharToInteger | "If the first non-white space character in the string is a hyphen (-), the integer value written to * Value is negative" (the 32-bit two's complement of what the digits make)
NT.DIGITS assumed | RtlUnicodeStringToInteger, RtlCharToInteger (the clean-room notes) | digits 0-9, A-F, a-f; the first that is not one or not below the base ends the number (the value so far is the answer); the value wraps modulo 2^32
NT.I2A.BASE doc | RtlIntegerToUnicodeString | RtlIntegerToChar and RtlIntegerToUnicodeString: "The only valid values are 0, 2, 8, 10, and 16." (0 is decimal); others return STATUS_INVALID_PARAMETER and write nothing
NT.I2A.DIGITS assumed | RtlIntegerToUnicodeString (the clean-room notes) | the value is unsigned; digits 0123456789ABCDEF (uppercase), at least one
NT.I2A.LENGTH assumed | (none) | RtlIntegerToChar with a length of 0 or more: more digits than the length returns STATUS_BUFFER_OVERFLOW (0x80000005) and writes nothing; otherwise the digits, and a NUL after them only when they are fewer than the length
NT.I2A.PAD assumed | (none) | RtlIntegerToChar with a negative length -L: more digits than L is STATUS_BUFFER_OVERFLOW; otherwise exactly L bytes, the digits right-aligned after '0' bytes, no NUL
NT.I2U.ANSI assumed | RtlIntegerToUnicodeString (the clean-room notes) | RtlIntegerToUnicodeString is RtlIntegerToChar into 33 bytes followed by RtlAnsiStringToUnicodeString(String, the digits, FALSE)
NT.A2U.SIZE assumed | RtlAnsiStringToUnicodeString (the clean-room notes) | without allocation: if 2 x the characters + 2 is more than MaximumLength, or Buffer is NULL, STATUS_BUFFER_OVERFLOW and nothing written; else Length = 2 x the characters, the units and a 0 unit after them, MaximumLength kept
NT.A2U.ASCII doc | RtlAnsiStringToUnicodeString | "The translation conforms to the current system locale information." (ASCII bytes become the same code points in every code page)
