GDI.TEXT.TM measured | golden text mfont-* | TEXTMETRIC of a TrueType font: lfHeight 0 is -16; ascent A and descent D are OS/2 usWinAscent and signed usWinDescent (no OS/2: head yMax and -yMin), the cell A + D (no OS/2: hhea ascender - descender); the scale is -lfHeight/upm below 0, lfHeight/cell above; tmAscent = round(A s), tmDescent = max(round(D s), 0), tmInternalLeading = tmHeight - round(s upm), tmExternalLeading = round(max(0, lineGap - (A + D - (hhea asc - desc))) s) (no OS/2: lineGap); tmMaxCharWidth = round((xMax - xMin) s) + 1 when bold; tmPitchAndFamily 7, 6 when fixed, 0x36 when fixed without OS/2; first, last, default and break chars 30 255 31 32; overhang 0 (round: half up)
GDI.TEXT.AVE measured | golden text mfont-* | tmAveCharWidth = round(xAvgCharWidth s) + 1 when bold; xAvgCharWidth 0: half of head's xMax - xMin; no OS/2: two thirds of it
GDI.TEXT.WIDTH measured | golden text mfont-* | GetCharWidth32: round(advance s), + 1 when bold and the advance is not 0; a character the cmap lacks takes glyph 0
GDI.TEXT.ABC measured | golden text mfont-* | GetCharABCWidths: on the rounded ppem the outline box's x edges snapped to 1/64 pixel; A = its left edge rounded half down, B = (right edge rounded half up) - A, at least 1, + 1 when bold; C = the width - A - B
GDI.TEXT.ABCEMPTY measured | golden text mfont-1, mfont-33 | an outline wholly above the ascent or below the descent (in font units, the edges included) has A 0, B 1 (no bold pixel), C the width - 1
GDI.TEXT.EXTENT measured | golden text mfont-* | GetTextExtentPoint32: the sum of the widths and tmHeight; GetTextExtentExPoint: the characters whose running width is at most the maximum, those running widths
GDI.TEXT.BITMAP measured | golden text mglyph-* (48 cases) | GetGlyphOutline GGO_BITMAP of a font the suite writes: the outline on the rounded ppem snapped to 1/64 pixel, a pixel lit where its center is inside or on an edge; a scan line through pixel centers crossing the outline between two of them lights the left (lower) pixel, the right (upper) one where the left lies before the black box's left (bottom) edge as GetCharABCWidths rounds it; bold ORs each pixel into its right neighbour; the buffer holds every row lit, the black box only the rows from round(-D s) to round(A s); an empty glyph: size 0, box 1 x 1 at (0, 0); gmCellIncX the width. GGO_METRICS: the same box (its return value is documented only as greater than zero)
GDI.TEXT.GRAY measured | golden text mglyph-* | GGO_GRAY8_BITMAP: GGO_BITMAP's rule on a grid 8 times finer (the 1/64-pixel outline times 8), each pixel the count of its 64 samples lit; bold adds each pixel's left neighbour, at most 64; rows of a whole number of DWORDs
GDI.TEXT.DRAW measured | golden text mglyph-* | TextOut (TA_TOP, TRANSPARENT) of a font the suite writes on a DIB: each character's GGO_BITMAP pixels within its black box's rows in the text color (no ClearType, no gray), the baseline tmAscent below y, the pen moving by each width
